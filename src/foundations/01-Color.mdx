# Color

**Decision:** blue `#0050ff` is the **primary structural** color — used as the deck's main color.
The palette has **three tiers**, and the choice always follows this order:

| Tier | What it is | When to use |
|---|---|---|
| **1 · Primary** | blue ramp, neutrals, surfaces, status, white | everything structural: background, text, border, main highlight |
| **2 · Secondary** | cyan, purple, mint, rose, orange (+ light/dark pairs and tints) | specific moments: tick, underline, label, card tint, one color per phase/step |
| **3 · Tertiary** | exact Figma values with no match in the DS | only inside the element/pattern that required them. Never for new content |

A color within ΔE 3 of a Tier 1/2 token does not become a tertiary: use the existing token.
Extracted from the *Auditoria Business Proposal* screens (VWDS.fig) — docs/foundations.md.

# Tier 2 · Secondary

## Accents — one per item

Rule: **one accent per phase/step/card** (never mix two in the same element). Each accent
resolves to the right shade automatically based on the background — light uses the darker/more saturated shade,
dark uses the pastel. `cyan` and `blue` fall back to white on `invert-blue` (same family as the background,
poor contrast); `cyan` only works as text on `invert-navy`.

## Do / Don't

**Do**
- Pick color by semantic role (`--color-text-primary`, `--color-surface`) — never by hex.
- Use accents on small elements: tick, underline, label, card tint.
- One accent per item in a row (phase 01 = purple, 02 = mint, 03 = blue — never two on the same one).

**Don't**
- Use an accent as a title color or main background color.
- Use `cyan` as text on a light background or on `invert-blue` (fails contrast — only works on navy).
- Invent a color outside the three tiers — if one is missing, it should become a token (Tier 3), not a loose hex.
- Use a tertiary in new content, or promote a tertiary to primary without a team decision.

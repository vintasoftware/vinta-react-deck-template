# Typography

**Decision (Farias):** Moderat leaves the deck, stays only on the website. Official font = **DM Sans**
(Google Font). Mono = **DM Mono**. Mandatory migration: Roboto → DM Sans · JetBrains Mono →
DM Mono · Inter → removed.

**DM Sans vs DM Mono — when to use each:** DM Sans carries title, body and subtitle — it is the voice
of the content. DM Mono is the **deck's signature** (harness: "it's not decoration") — reserved for
eyebrow, label, value/stat and anything that looks like data (not titles, not paragraphs).

## Do / Don't

**Do**
- Use the right role for the content: mono for eyebrow/label/value, sans for title/body.
- When a role doesn't exist in the scale (e.g. ~36, ~42), reuse the closest neighbor and
  document it — don't invent a new size without recording it in tokens.css.

**Don't**
- Use Roboto, JetBrains Mono or Inter — all migrated.
- Use DM Mono for title or body — it's a data signature, not decoration.

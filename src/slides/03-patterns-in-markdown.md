# Patterns work
# in markdown too

Name a design-system pattern in the frontmatter and the body fills it.

## Pick a pattern
Browse /patterns, then set template: SlideNumberedList (or any pattern's name).

## Write a two-tone title
Two "#" lines in a row: the second one becomes the accent line.

## Keep everything else
Kicker above the title, "##" sections, lists, tables, images and speaker notes.
